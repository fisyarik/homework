# Глоссарий SQL‑команд по лабораторным работам

база данных - комплекс данных (информации), которые структурирваны и взаимосвязаны между собой
SQL - реляционная база данных

схема данных - схема показывающая все таблицы данных в этой БД и все связи в них

**Структура языка SQL**

- Операторы определения данных(DDL Data Definition Language) |CREATE TABLE|
                                                           |DROP TABLE|
                                                           |ALTER TABLE|
                                                           |CREATE VIEW|
                                                           |ALTER VIEW|
                                                           |DROP VIEW|
                                                           |CREATE \ INDEX|
                                                           |DROP INDEX|
- Опереаторы манипулирования данными |DELETE|
                                     |INSERT|
                                     |UPDATE|
                                     |SELECT|

- Средства администрирования данных |GRANT|
                                    |REVOKE|
                                    |DENY|
- Средства управления транзакциями |COMMIT|
                                   |ROLLBACK|
                                   |SAVEPOINT|

## Лабораторная 2

| Команда/Оператор | Описание | Пример использования |
|---------------|----------|--------------------|
| `SELECT *` | Выбор всех столбцов таблицы | `SELECT * FROM Академик` |
| `SELECT <столбцы>` | Выбор конкретных столбцов | `SELECT ФИО, Дата_рождения FROM Академик` |
| `+` | Конкатенация строк или арифметическое сложение | `N'Академик ' + ФИО + N'Специализация: ' + Специализация` |
| `AS` | Задание псевдонима столбцу | `AS Информация` |
| `DISTINCT` | Отбор уникальных значений | `SELECT DISTINCT Специализация FROM Академик` |
| `ORDER BY` | Сортировка результатов | `ORDER BY Год_присвоения_звания` |
| `TOP N` | Ограничение вывода первыми N строками | `SELECT TOP 2 * FROM Академик` |
| `TOP N PERCENT` | Ограничение вывода первыми N % строк | `TOP 30 PERCENT` |
| `WITH TIES` | Включение строк с одинаковым значением сортировки (с `TOP`) | `TOP 4 WITH TIES` |
| `OFFSET N ROWS` | Пропуск первых N строк | `OFFSET 2 ROWS` |
| `FETCH NEXT N ROWS ONLY` | Возврат N строк после пропуска (с `OFFSET`) | `FETCH NEXT 8 ROWS ONLY` |

## Лабораторная 3

| Команда/Оператор | Описание | Пример использования |
|---------------|----------|--------------------|
| `WHERE` | Фильтрация по условиям | `WHERE Континент != 'Африка'` |
| `!=` / `<>` | Оператор «не равно» | `Континент != 'Европа'` |
| `AND` / `OR` | Логические операторы | `Население > 5000000 AND Площадь < 100000` |
| `LIKE` / `NOT LIKE` | Поиск по шаблону (`%` — любые символы, `_` — один символ) | `Название LIKE '__а%'` |
| `IS NOT NULL` | Проверка на не‑пустое значение | `Столица IS NOT NULL` |
| `IN` | Проверка вхождения в список | `Континент IN ('Африка', 'Северная Америка')` |

## Лабораторная 4

| Функция | Описание | Пример использования |
|-------|----------|--------------------|
| `LEN()` | Возвращает длину строки | `LEN(ФИО) AS Количество_символов` |
| `TRIM()` | Удаляет пробелы в начале и конце строки | `TRIM(ФИО) AS ФИО` |
| `CHARINDEX()` | Ищет позицию подстроки в строке | `CHARINDEX('ов', ФИО) AS Позиция_ов` |
| `RIGHT()` | Извлекает указанное количество символов с конца строки | `RIGHT(Специализация, 2) AS Спец_2` |
| `REVERSE()` | Переворачивает строку | `REVERSE(Специализация) AS Специализация_обратно` |
| `REPLICATE()` | Повторяет строку указанное количество раз | `REPLICATE(N'Перепёлкина', 17)` |
| `ROUND()` | Округляет число до указанного количества знаков | `ROUND(AVG(Население), 1)` |
| `ABS()` | Модуль числа | `ABS(POWER(SIN(PI()/2), 2) - COS(3*PI()/2))` |
| `POWER()` | Возведение в степень | `POWER(SIN(PI()/2), 2)` |
| `SIN()`, `COS()`, `PI()` | Математические функции | `SIN(PI()/2)` |
| `DATEDIFF()` | Разница между датами | `DATEDIFF(DAY, GETDATE(), '2026-05-26')` |
| `GETDATE()` | Текущая дата и время | `GETDATE()` |
| `YEAR()` | Извлечение года из даты | `YEAR(Дата_рождения)` |
| `CASE` | Условная логика | `CASE WHEN (YEAR(Дата_рождения) % 4 = 0 ...) THEN N'Високосный' ELSE N'Не високосный' END` |

## Лабораторная 5

| Функция/Оператор | Описание | Пример использования |
|--------------|----------|--------------------|
| `MIN()` | Минимальное значение | `MIN(Площадь) AS МинимальнаяПлощадь` |
| `MAX()` | Максимальное значение | `MAX(Население) AS МаксНаселение` |
| `AVG()` | Среднее значение | `AVG(Население)` |
| `COUNT()` | Подсчёт строк | `COUNT(*) AS КоличествоСтран` |
| `GROUP BY` | Группировка по столбцам | `GROUP BY Континент` |
| `HAVING` | Фильтрация групп (после `GROUP BY`) | `HAVING AVG(Население / Площадь) > 30` |
| `SUM()` | Сумма значений | `SUM(Население) AS ТекущееНаселение` |

## Лабораторная 6

| Команда/Оператор | Описание | Пример использования |
|--------------|----------|--------------------|
| `JOIN` / `INNER JOIN` | Объединение таблиц (только совпадающие строки) | `JOIN [Экзамен] э ON ст.[Рег_номер] = э.[Рег_номер]` |
| `LEFT OUTER JOIN` | Все строки из левой таблицы + совпадающие из правой | `LEFT OUTER JOIN Сотрудник Р ON С.Шеф = Р.Таб_номер` |
| `ON` | Условие соединения таблиц | `ON С.Номер = Спец.Номер` |
| `BETWEEN` | Диапазон значений (включительно) | `BETWEEN '2015-06-01' AND '2015-06-30'` |
| `LOWER()` | Преобразование в нижний регистр | `LOWER(Каф.факультет) LIKE '%ит%'` |

| Оператор | Описание | Пример использования |

## Лабораторная 8

| Конструкция/Оператор | Описание | Пример использования |
|------------------|----------|--------------------|
| Подзапросы `(SELECT ...)` | Вложенные запросы для вычислений | `(SELECT SUM(Площадь) FROM Страна)` |
| `ALL` | Сравнение со всеми значениями подзапроса | `Население > ALL (SELECT Население FROM Страна WHERE Континент = 'Африка')` |
| `ANY` | Сравнение с любым значением подзапроса | `Население > ANY (SELECT Население FROM Страна WHERE Континент = 'Южная Америка')` |
| `EXISTS` | Проверка существования записей в подзапросе | `EXISTS (SELECT 1 FROM Страна WHERE Континент = 'Африка' AND Площадь > 200000)` |
| `WITH` | Создание временных таблиц (CTE) | `WITH Средняя_плотность_по_континентам AS (SELECT Континент, AVG(...) FROM Страна GROUP BY Континент)` |

## Лабораторная 9

| Команда | Описание | Пример использования |
|-------|----------|--------------------|
| `CREATE TABLE` | Создание новой таблицы | `CREATE TABLE Управление_фиса (...)` |
| `PRIMARY KEY` | Определение первичного ключа | `ID INT IDENTITY(1,1) PRIMARY KEY` |
| `IDENTITY(1,1)` | Автоинкремент для числового поля | `Код_цветка INT IDENTITY(1,1) PRIMARY KEY` |
| `DEFAULT` | Значение по умолчанию для столбца | `Дата_создания DATE DEFAULT GETDATE()` |
| `CHECK` | Ограничение на значения столбца | `Площадь DECIMAL(12,2) CHECK (Площадь > 0)` |
| `UNIQUE` | Уникальность значения в столбце | `ID INT UNIQUE` |

## Лабораторная 10

| Команда | Описание | Пример использования |
|-------|----------|--------------------|
| `INSERT INTO` | Добавление новых записей | `INSERT INTO Ученик (Фамилия, Предмет, Школа, Баллы) VALUES ('Трошков', 'Химия', 'Школа №18', NULL)` |

| `TRUNCATE TABLE` | Полное удаление всех данных из таблицы | `TRUNCATE TABLE Гимназист` |
